🔒 How Secure Retrieval Works
  1. The encrypted file is fetched from IPFS using its content-addressed CID
  2. SHA-256 hash is computed and compared against the original hash for integrity
  3. AES-256-GCM decryption is performed using your 256-bit key and 12-byte IV
  4. The original PNG image data is rendered directly in-browser — no server needed
  5. The decrypted image never leaves your device during this process
